# お問い合わせフォーム（別リポジトリ用）

## 公開のしかた（GitHub Pages）
1. 新しいリポジトリを作り、このフォルダの中身をpushする（.github フォルダも忘れずに）
2. Settings → Pages → Source を「GitHub Actions」にする
3. 緑のチェックが付いたら、https://ユーザー名.github.io/リポジトリ名/ で開ける

## Googleフォームの用意（送信先）
1. Googleフォームを新しく作り、質問を4つ作る（すべて「記述式」がおすすめ）
   お名前 ／ メールアドレス ／ 種類 ／ メッセージ（こちらは「段落」）
   ※「種類」をプルダウンにする場合は、選択肢を config.js の categories と完全に同じ文字にする（違うと、回答が記録されません）
2. フォームの「設定」→「回答」で、次の2つを必ずオフにする
   ・メールアドレスを収集　・回答を1回に制限
   （オンだと、Googleへのログインが必要になり、サイトから送れません）
3. 右上の「︙」→「事前入力したURLを取得」を開き、各質問に次の文字を入力する
   お名前 → name ／ メールアドレス → email ／ 種類 → category ／ メッセージ → message
4. 「リンクを取得」→「リンクをコピー」
5. 公開したサイトの setup.html を開き、コピーしたリンクを貼る → 出てきた文字を config.js の form に貼る
   （ローカルで試すなら、python -m http.server で開いた setup.html でもOK）
6. pushする。1〜2分で、送信できるようになる

回答は、フォームの「回答」タブ（またはスプレッドシート）で見られる。通知メールが欲しいときは、
フォームの「回答」→「︙」→「新しい回答についてのメール通知を受け取る」をオンにする。

## 書き換えるのは config.js だけ
- ヘッダーのメニュー（TOP・ブログと同じ形）、文章、種類の選択肢、注意書き
- 「雑記」のメニューは、ブログのURLを入れると出る
- TOPの config.js のリンク（links）に、このページのURLを入れると、TOPからも行ける

## しくみと注意
- 送信は、ブラウザからGoogleフォームへ直接送っている（サーバーは使わない）
- Googleの返事は、ブラウザの決まりで読めないため、「通信できたら成功」として完了画面を出している。
  設定の間違い（欄の番号違い・選択肢の不一致・ログイン必須の設定）があっても、完了画面は出てしまう。
  最初に、本番のURLで1通テスト送信して、フォームの「回答」に届くか必ず確認してください
- 迷惑対策として、見えない入力欄（入力があれば送らない）と、30秒の連続送信制限を入れている。強い対策ではない
- 通信に失敗したときは、Googleフォームを直接開くリンクが出る
