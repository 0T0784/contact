Googleフォームの設定

  1. Googleフォームを作り、質問を4つ作る（すべて「記述式」がおすすめ）：お名前／メールアドレス／種類／メッセージ（メッセージは「段落」）
  2. フォームの設定で、「メールアドレスを収集」と「回答を1回に制限」をオフにする（オンだとログインが必要になり、送れません）
  3. 右上の ︙ →「事前入力したURLを取得」を開き、各質問に 次の文字を入力する
    お名前 → name　メールアドレス → email　種類 → category　メッセージ → message
  4. 「リンクを取得」→「リンクをコピー」して、下に貼る


    

    
できた文字を、config.js の form の部分に貼り付けてください。設定が終わったら、このページ（setup.html / setup.js）は消して構いません。
